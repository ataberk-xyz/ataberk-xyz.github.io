# Blog TR/EN Per-Post Language Option Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Per-post Turkish translations living in a `tr` collection under `/tr/...` URLs, with an `EN · TR` link on paired posts, hreflang tags, and a Turkish version of the latest post.

**Architecture:** Turkish documents live in `_tr/` (Jekyll collection, not `site.posts`), so homepage/categories/pagination/RSS/N° numbering are untouched. Pairing key is the identical filename across `_posts/` and `_tr/`; one include resolves a page's counterpart URL and is reused by the post layout (toggle + N°) and `head.html` (hreflang).

**Tech Stack:** Jekyll 3.x (legacy GitHub Pages build — core features only), Liquid, dart-sass for local CSS checks.

**Spec:** `docs/superpowers/specs/2026-08-10-blog-i18n-design.md`

## Global Constraints

- GitHub Pages legacy build: no custom plugins, Jekyll 3.x collection permalinks don't support `:categories/:year/:month/:day` — TR files carry an explicit `permalink:`.
- Chrome stays English everywhere (masthead, nav, categories, ledger labels, related-posts, "Written by", "MIN").
- No pills/chips anywhere (standing theme decision) — language links are plain text in the meta line.
- Translation policy: prose TR; technical terms, code blocks, tables, CVE/CWE ids, ledger values EN.
- Jekyll is not installed locally. Liquid changes are verified live after push (Task 6). Each task still commits locally; nothing is pushed before Task 6.
- The Turkish draft is NOT committed until Ataberk reviews it (Task 5 gate). Nothing is pushed without his go-ahead on the translation.
- All repo work happens in `~/Desktop/projects/saiyajin-blog/` on `master`.

### Task 2: Pairing lookup include

**Files:**
- Create: `_includes/translation-url.html`

**Interfaces:**
- Consumes: `site.tr` (Task 1), `include.post` (a post or TR doc object).
- Produces: prints the counterpart's `url` (no `site.baseurl` prefix), or nothing. Callers use the capture pattern:
  `{% capture t_url %}{% include translation-url.html post=page %}{% endcapture %}{% assign t_url = t_url | strip %}` then test `t_url != ""`.

- [ ] **Step 1: Create `_includes/translation-url.html`**

```liquid
{%- comment -%}
  Prints the URL of include.post's counterpart in the other language, or
  nothing. Pairing key: identical filename in _posts/ and _tr/. Output has
  no baseurl prefix; callers capture and strip (see post.html, head.html).
{%- endcomment -%}
{%- assign tu_name = include.post.path | split: "/" | last -%}
{%- if include.post.lang == "tr" -%}
  {%- for tu_p in site.posts -%}
    {%- assign tu_pname = tu_p.path | split: "/" | last -%}
    {%- if tu_pname == tu_name -%}{{ tu_p.url }}{%- break -%}{%- endif -%}
  {%- endfor -%}
{%- else -%}
  {%- for tu_d in site.tr -%}
    {%- assign tu_dname = tu_d.path | split: "/" | last -%}
    {%- if tu_dname == tu_name -%}{{ tu_d.url }}{%- break -%}{%- endif -%}
  {%- endfor -%}
{%- endif -%}
```

- [ ] **Step 2: Commit**

```bash
git add _includes/translation-url.html
git commit -m "i18n: translation-url include, filename-keyed pairing lookup"
```

### Task 4: hreflang alternates in `head.html`

**Files:**
- Modify: `_includes/head.html` (after the RSS `<link>`, line 39)

**Interfaces:**
- Consumes: `translation-url.html` capture pattern (Task 2).

- [ ] **Step 1: Add the hreflang block**

In `_includes/head.html`, insert after the RSS line (`<link rel="alternate" type="application/rss+xml" ...`):

```liquid
  {%- comment -%} hreflang pair — only on posts that have a counterpart.
      EN is x-default. Absolute URLs via site.url (must stay set in config;
      a blank url was the old sitewide-404 root cause). {%- endcomment -%}
  {% if page.layout == 'post' %}
    {% capture hl_t %}{% include translation-url.html post=page %}{% endcapture %}
    {% assign hl_t = hl_t | strip %}
    {% if hl_t != "" %}
      {% if page.lang == "tr" %}
        {% assign hl_en = hl_t %}{% assign hl_tr = page.url %}
      {% else %}
        {% assign hl_en = page.url %}{% assign hl_tr = hl_t %}
      {% endif %}
  <link rel="alternate" hreflang="en" href="{{ site.url }}{{ site.baseurl }}{{ hl_en }}" />
  <link rel="alternate" hreflang="tr" href="{{ site.url }}{{ site.baseurl }}{{ hl_tr }}" />
  <link rel="alternate" hreflang="x-default" href="{{ site.url }}{{ site.baseurl }}{{ hl_en }}" />
    {% endif %}
  {% endif %}
```

- [ ] **Step 2: Commit**

```bash
git add _includes/head.html
git commit -m "i18n: reciprocal hreflang alternates on translated posts"
```
